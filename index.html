FEATURES

功能特性

一套源码，覆盖即时通讯全场景

实时私聊

支持文字、图片、视频消息，1 秒轮询实时刷新未读，红点角标提醒，长会话自动滚动到底部。

好友系统

按用户名搜索、发送好友请求、双向验证、备注昵称、删除并清空聊天记录，权限可精细控制。

朋友圈

发布图文动态（最多 9 张图）、点赞、评论、删除，玻璃拟态卡片配 #FDB59F 甜美主题。

实名认证

真实姓名 + 18 位身份证号格式校验，绑定账号邮箱，身份证号脱敏显示，同一证件不可重复绑定。

后台管理

管理员面板：用户列表、统计数据、禁用/启用账号、重置密码、设置角色、查看用户详情。

隐私设置

朋友圈权限（所有人/仅好友/仅自己）、是否允许被搜索、是否允许被添加好友、是否在发现页展示。

大文件上传

单文件最大 1000MB，按日期目录存储、唯一文件名防冲突，本地图/视频即时预览，删除数据同步删文件。

一键安装

向导式 install.php，三步完成：检测环境→填写数据库→创建表与管理员，自动生成 config.php。

唯美 UI

Vant 4 + Remix Icon + Vue 3 SPA，#FDB59F 桃色主题，毛玻璃卡片、粉色按钮、统一的甜美视觉语言。

INSTALL

安装指南

三步即装，开箱即用

1

下载并解压

下载 简讯聊天cms.zip，解压到 PHP 运行环境根目录（推荐 PHP 8.0+ / MySQL 5.7+）。

2

访问 install.php

浏览器打开 http://你的域名/install.php，填写数据库地址、账号、密码、库名及管理员信息。

3

安装完成

系统自动创建 5 张数据表与默认管理员，生成 config.php，访问首页即可登录使用。

提示：为保证上传大文件正常，建议在 php.ini 中设置 upload_max_filesize = 1000M 与 post_max_size = 1000M。
